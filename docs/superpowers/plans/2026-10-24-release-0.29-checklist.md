## Upgrading to 0.29 — notes for site owners

Also in the Folio README (`list`: the admin list). Put these in the release notes.

- **List order:** lists without `list.sort` / `orderable` now end in record-id order — on
  SQLite this replaces insertion order. Add `list.sort` where the order matters.
- **`onDelete: detach` is the default:** deleting a record rewrites every record pointing at
  it (publishing types get unpublished working-copy changes; `BeforeSave` / `AfterSave` hooks
  run). Declare `onDelete` explicitly where that matters.
- **List markup:** a tick column (`folio-bulk-cell`) and sortable headers were added; site
  tests that read columns by position need updating (see smart-stack.works above).
- **`storage/cache/data`** (JSON query cache, with `json-{type}.gen` generation files) must be
  writable and git-ignored.
- **Hidden fields** are no longer searched by loose search (list `q`, the relation picker,
  relation search) unless they say `"searchable": true`; mark secrets `"searchable": false`.

## Notes

- `search()` is unchanged. Lists use `searchLoose()`.
- The list markup changed: sortable `th`, a tick column (`folio-bulk-cell`) before the
  columns, cells rendered from `row.marked`. Tests that read cells by position must skip
  `folio-bulk-cell`.
- Lists without a `sort` / `orderable` order end in the record id: row order is stable but not
  insertion order.
