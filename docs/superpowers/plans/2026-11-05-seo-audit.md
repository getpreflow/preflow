# `preflow seo:audit` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An on-demand, resumable SEO/GEO audit of a site's own environment — terminal output plus a JSON report Folio shows read-only — with built-in checks, a plumbing for site checks, and no trace in the site's data.

**Architecture:** Core gets an "internal render" request marker that redirects, media and the debug toolbar honour. preflow/view gets the audit engine (`Preflow\View\Audit`): checks, findings, a page renderer reusing GEO's clean sub-request, a resumable run that writes the report, and the built-in checks. The `seo:audit` command drives it. Folio adds the read-only screen and resolves "where to fix" (record/asset). holz-objekte.org registers two example checks after the framework release.

**Tech Stack:** PHP 8.4+, PHPUnit 11, PSR-7/15 (nyholm), DOM (ext-dom) for HTML parsing, Twig (Folio screen).

**Spec:** `docs/superpowers/specs/2026-11-05-seo-audit-design.md`

## Global Constraints

- On demand only; never part of a deploy; exit code 0 for a completed or partial audit with findings, non-zero only for usage/boot errors.
- Severities exactly: `critical`, `warning`, `notice`. No score.
- Each environment checks itself: renders inside the app (no network), report in that environment's storage (`storage/data/seo-audit.json` unless the builder finds a better shared-storage path — say why).
- Renders are anonymous (no cookies/session/query), production-like: debug toolbar and debug-only output off for audit renders; 5xx reported.
- No trace: audit renders are marked internal; RedirectMiddleware records no not-found entry and counts no hit for them; media generates no variant for them (a missing variant is reported as missing, not created); sites can read the marker.
- Audited pages = `PublicPages` for every locale (incl. sitemap/llms exclusions). Link targets: status check only, once per run; no query-string URLs, nothing robots.txt disallows.
- Resumable in batches: progress saved in the report; re-running continues; `--fresh` starts over; report status `complete` or `incomplete` with done/total; a run stops itself before a time budget (default 600 s, flag to change) and says how to continue.
- Folio: read-only screen of the last report, a new permission, texts in en/de/fr; links to the page and, for content findings, to the record or asset editor.
- Site checks via a public registry; findings in the same shape as built-in ones.
- Release as Preflow 0.54.0 (owner go-ahead) before the holz-objekte task.

## Review Focus

- A page that throws (5xx) or times out mid-render: reported as critical, the run continues (Task 3 test).
- Killed mid-batch (process ends between pages): the next run resumes without duplicating findings or losing pages (Task 3 test: simulate by stopping after N pages, then resume).
- A site with SEO or GEO off: checks that need them are skipped, not reported as failures (Task 5 test).
- JSON-only site without Folio's SQL tables (smeyer.me): runs and writes the report (Task 6 test on a JSON app).
- Non-ASCII titles/paths and three locales: findings name the right locale and URL encoding (Task 4 test with de/fr pages and an umlaut title).

**Files:** create `packages/core/src/Http/InternalRender.php`; modify `packages/routing/src/Redirect/RedirectMiddleware.php`, `packages/media/src/Http/VariantController.php`, `packages/devtools/src/Http/DebugToolbarMiddleware.php`; tests next to each package's existing tests.

**Interfaces:**
- Produces: `final class InternalRender { public const string ATTRIBUTE = 'preflow.internal_render'; public static function is(ServerRequestInterface $r): bool; public static function mark(ServerRequestInterface $r): ServerRequestInterface; }` ("since 0.54").

- [ ] **Step 1: Failing tests:** RedirectMiddleware: a marked request ending in 404 records nothing in the NotFoundLog and a marked redirect hit calls no `hit()` (the redirect itself still answers); VariantController: a marked request for a missing variant answers 404 and creates no file; DebugToolbarMiddleware: a marked HTML response gets no toolbar. Unmarked requests behave as today.
- [ ] **Step 2: Run** — fail. **Step 3: Implement.** **Step 4: Run** each package's tests — pass.
- [ ] **Step 5: Commit** `feat(core): an internal-render marker that redirects, media and the debug toolbar honour`

### Task 2 (view): audit engine — findings, checks, registry, renderer

**Files:** create in `packages/view/src/Audit/`: `Severity.php` (enum critical/warning/notice), `Finding.php`, `Target.php`, `PageCheck.php`, `SiteCheck.php`, `RunCheck.php`, `AuditRegistry.php`, `PageRenderer.php`, `RenderedPage.php`; tests in `packages/view/tests/Audit/`.

**Interfaces (produces):**
- `final readonly class Finding(string $check, Severity $severity, string $message, string $url = '', string $locale = '', ?Target $target = null)` with `toArray(): array` / `fromArray(array): self`.
- `final readonly class Target(string $kind /* 'record'|'asset' */, string $type, string $id)`.
- `interface PageCheck { public function id(): string; /** @return list<Finding> */ public function check(RenderedPage $page): array; }`
- `interface SiteCheck { public function id(): string; /** @return list<Finding> */ public function check(PageRenderer $renderer): array; }`
- `interface RunCheck { public function id(): string; public function collect(RenderedPage $page): void; /** @return list<Finding> */ public function finish(): array; public function state(): array; public function restore(array $state): void; }` (cross-page checks: duplicates, hreflang, links).
- `final class AuditRegistry { addPage(PageCheck), addSite(SiteCheck), addRun(RunCheck), setTargets(\Closure(string $url, string $locale): ?Target), pageChecks(), siteChecks(), runChecks(), target(string, string): ?Target }` — bound as a container singleton; sites register from a service provider.
- `final class PageRenderer { render(string $path): RenderedPage }` — builds the request like GEO's `subRequest()` (clean GET, no session, `InternalRender::mark`), runs it through the app's pipeline inside `RenderScopes`; never throws: a thrown error becomes a `RenderedPage` with status 500 and the message.
- `final readonly class RenderedPage(string $url, string $locale, int $status, array $headers, string $body)` with `dom(): ?\DOMDocument` (lazy, parsed once, libxml errors suppressed) and `header(string): string`.

- [ ] **Step 1: Failing tests:** Finding round-trips through toArray/fromArray; the registry returns registered checks in order; PageRenderer on a small app: a page answers 200 with its body, a throwing route gives 500 (no exception), the request carried the marker and no session cookie, the debug toolbar is absent with `app.debug` on.
- [ ] **Step 2–4:** fail, implement, pass (`vendor/bin/phpunit packages/view/tests/Audit`).
- [ ] **Step 5: Commit** `feat(view): the audit engine — findings, check interfaces, registry, page renderer`

### Task 3 (view): the resumable run and the report

**Files:** `packages/view/src/Audit/AuditRun.php`, `packages/view/src/Audit/AuditReport.php`; tests.

**Interfaces:**
- Consumes Task 2.
- Produces: `AuditReport` (JSON on disk): `{version: 1, started_at, finished_at|null, status: "complete"|"incomplete", origin, pages: {total, done}, counts: {critical, warning, notice}, findings: [Finding…], state: {queue: [[path, locale]…], cursor, run: {checkId: state}}}`; `AuditReport::load(string $file): ?self`, `save(string $file): void` (atomic write: temp + rename).
- `AuditRun::__construct(AuditRegistry, PageRenderer, PublicPages, string $file, \Closure $now)`; `run(int $timeBudgetSeconds, ?int $limit, ?string $onlyUrl, bool $fresh, ?\Closure $progress): AuditReport` — builds the queue from `PublicPages` (all locales) on a fresh run, renders and checks page by page, saves after every page (or every N pages — builder's call, ≤ 5 s of work lost), stops before the budget, runs site checks and `RunCheck::finish()` only when the queue is done, then status `complete`.

- [ ] **Step 1: Failing tests:** a fresh run over 3 pages writes a complete report with counts; a budget that stops after page 1 leaves `incomplete` (1 of 3); a second run continues and completes with no duplicate findings; `--fresh` after a complete run starts over; a page that 500s yields one critical finding and the run continues; the report file is replaced atomically.
- [ ] **Step 2–4.** **Step 5: Commit** `feat(view): resumable audit runs and the JSON report`

### Task 4 (view): built-in page and run checks

**Files:** `packages/view/src/Audit/Checks/*.php` (one class per check), registered by `ViewServiceProvider` (or wherever view binds SEO services) on the registry; tests one file per check group.

Checks (id → severity): `title.missing` critical; `title.duplicate` (RunCheck, same locale) warning; `description.missing` warning; `description.duplicate` (RunCheck) notice; `img.alt-missing` warning (an `alt=""` is fine); `og.image-alt-missing` notice; `h1.count` (none or >1) notice; `aria-hidden.focusable` warning; `canonical.missing` notice; `canonical.foreign-host` warning (host ≠ app.url's); `noindex.in-sitemap` critical (page noindex but in the sitemap list); `hreflang.unpaired` (RunCheck: an alternate whose page isn't audited/200 or doesn't link back) warning; `hreflang.x-default-missing` (multilingual sites) notice; `link.broken` (RunCheck: internal `href`/`src` targets status-checked once via PageRenderer; 404/5xx critical; a redirect chain of ≥2 hops notice; skips query-string URLs and robots-disallowed paths); `status.error` (page 5xx) critical. Each finding sets `target` via `AuditRegistry::target()` when the url is a page.

- [ ] **Step 1: Failing tests:** for each check a passing and a failing HTML/page fixture; de/fr pages with an umlaut title produce findings naming the right locale and the encoded URL; link checking renders each target once (count renders) and never follows `?q=` or a disallowed path.
- [ ] **Step 2–4.** **Step 5: Commit** `feat(view): built-in audit checks for pages, links and language versions`

### Task 5 (view): built-in site checks

**Files:** `packages/view/src/Audit/Checks/Site*.php`; tests.

Checks: `robots.missing`/`sitemap.missing`/`sitemap.invalid`/`llms.missing` (only when SEO / GEO are enabled; otherwise skipped) critical/warning; `sitemap.non200` (a listed URL that isn't 200) critical; `notfound.status` (a made-up path doesn't answer 404) critical; `notfound.no-home-link` warning; `favicon.raster-missing` (no raster icon ≥48 px linked and no `/favicon.ico`) warning; `apple-touch.missing` notice; `manifest.missing` notice; `etag.unstable` (two renders of the home page give different ETags) notice; `etag.no-304` (its own ETag doesn't give 304) notice; `share-image.missing` (SEO on, no site share image) notice; `owner.missing` (SEO on, no owner) notice.

- [ ] **Step 1: Failing tests:** each check passing/failing on small apps; SEO/GEO off → those checks produce nothing.
- [ ] **Step 2–4.** **Step 5: Commit** `feat(view): built-in site checks (robots, sitemap, llms, 404, icons, caching)`
