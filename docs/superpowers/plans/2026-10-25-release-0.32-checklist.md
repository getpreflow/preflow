# Release 0.32 checklist

Mail redirect (preflow/notify): a transport's `redirect_to` sends every email to fixed
addresses instead of its recipients. Asked for by holz-objekte.org: its stage uses the live
mail setup, but every mail must reach the owner only. Released 2026-10-25 from `main`
(owner's request the same day). Notify README ("Configuration") and the roadmap entry are
updated. No new package, no constraint change.

Test runs before release (2026-10-25):
- `vendor/bin/phpunit packages/notify`: 61 tests, 168 assertions, green.
- `vendor/bin/phpunit` (no MySQL env): 2953 tests, 87 skipped, green (PHPUnit Deprecations: 99, unchanged).

## The API

- `Preflow\Notify\Transport\RedirectTransport(Transport $inner, list<string> $recipients)`;
  `recipients()`. Emails: To = the recipients, Cc/Bcc empty, From/Reply-To/attachments kept,
  subject `[→ <original To, comma-separated>] <subject>`, text starts with
  `Redirected. To: …; Cc: …; Bcc: …` and a blank line, HTML (when present) with the same line
  in a small grey `<p>`. Other messages go to the inner transport unchanged.
- `TransportFactory::get()` wraps any transport whose config has a non-empty `redirect_to`.
