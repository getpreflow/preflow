# GEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every public page of a Preflow site can be read by AI assistants as clean Markdown (`/page.md`, `Accept: text/markdown`), listed in `/llms.txt` and joined in `/llms-full.txt`; components refine their Markdown with `{% apply geo %}`.

**Architecture:** All GEO code lives in `packages/view/src/Geo/` (view already depends on core, and both the twig/blade engines and the component renderer depend on view — no new package, so no new split repo or Packagist entry). A request-scoped `GeoCollector` records geo blocks per component render; during a Markdown render the component renderer swaps a component's HTML for a placeholder that the HTML→Markdown converter replaces with the block. An outermost `GeoMiddleware` (booted by `Application::bootGeo()` from `config/geo.php`) answers `.md`, `Accept: text/markdown`, `llms.txt` and `llms-full.txt` by sending a cookie-less copy of the request down the normal pipeline and converting the HTML it gets back. Folio contributes its published pages to a `GeoEntries` registry.

**Tech Stack:** PHP 8.4 (`Dom\HTMLDocument` for parsing — no new dependency), Twig, Blade, PSR-15, PHPUnit.

**Spec:** `docs/superpowers/specs/2026-11-01-geo-design.md`

## Global Constraints

- GEO is opt-in: without `config/geo.php` or with `'enabled' => false`, no behaviour and no HTML output changes (existing tests green unchanged).
- Markdown is always the anonymous public view: the internal render carries no `Cookie` header and no session; responses never carry `Set-Cookie`.
- Never a Markdown view for: non-200 responses (incl. redirects), `X-Robots-Tag: noindex`, `<meta name="robots" content="noindex">` (any content containing `noindex`), Folio previews → `404`.
- Converter input: the page's `<main>` (else `<body>`); removed before conversion: `script, style, template, svg, noscript, iframe, form controls (input, select, textarea, button), [hidden], [aria-hidden="true"], [data-geo="skip"]`.
- Links and images in Markdown use absolute URLs (origin = `app.url`, else the request's scheme+host); images only with non-empty `alt`.
- `.md` URLs: `/about` → `/about.md`, home `/` → `/index.md`, `/de/` → `/de/index.md`.
- `llms.txt` format: `# {name}`, blank line, `> {summary}`, then `## {section}` blocks of `- [{title}]({md-url}): {description}` (`: description` omitted when empty); default-locale file ends with `## Other languages` linking `/{locale}/llms.txt`.
- Config file `config/geo.php` keys (exact): `enabled` (bool), `name` (?string), `summary` (?string), `site_fields` (array, default `['name' => 'name', 'summary' => 'meta_description']`, read from Folio's `site` singleton when `name`/`summary` are null), `types` (list, default `['page']`), `noindex_field` (?string, default null), `full` (bool, default true), `exclude` (list of paths, default `[]`).
- Strict CSP untouched; framework suite `vendor/bin/phpunit` (≈4953 tests, 10-minute timeout) and `node --test 'packages/folio/tests/js/*.test.mjs'` green.
- Branch `feat/geo` from `main`; no tag/push/merge (controller releases 0.49.0).

## Review Focus

1. A page with nested components where only the inner one has a geo block (and the reverse) → the right Markdown in the right place, nothing duplicated.
2. A signed-in visitor (session cookie) requesting `/about.md` → the anonymous page's Markdown, no `Set-Cookie`, no personal text.
3. A page that redirects, 404s or is `noindex` → `.md` is 404 and it is not in `llms-full.txt`.
4. Relative links and images in component HTML → absolute in Markdown; decorative images (no alt) gone; navigation outside `<main>` gone.
5. `llms-full.txt` over several pages → each page rendered independently (no CSS/geo blocks bleeding between pages), one failing page skipped, not fatal.

### Task 1: Geo blocks are collected per component

**Files:**
- Create: `packages/view/src/Geo/GeoCollector.php`
- Modify: `packages/twig/src/PreflowExtension.php` (filter `geo`), `packages/blade/src/BladeEngine.php` (`@geo … @endgeo`, like `@css`), `packages/components/src/ComponentRenderer.php` (frames + placeholder), the place where the container builds `PreflowExtension`/`ComponentRenderer` (`packages/core/src/Application.php` view/component boot) to inject the shared collector
- Test: `packages/view/tests/Geo/GeoCollectorTest.php`, `packages/components/tests/ComponentRendererGeoTest.php`, `packages/twig/tests/PreflowExtensionTest.php` (extend), a Blade test next to the existing `@css` test

**Interfaces:**
- Produces:
  - `final class Preflow\View\Geo\GeoCollector` (request-scoped singleton in the container):
    - `capture(bool $on): void`, `capturing(): bool` — blocks are only recorded while capturing (normal HTML renders record nothing).
    - `enter(): void` / `leave(): ?string` — open/close a frame around one component render; `leave()` returns that frame's block (`''` for an empty block, `null` when the component has none).
    - `add(string $markdown): void` — called by the filter/directive; appends (trimmed) to the innermost open frame, or to a page-level list when no frame is open.
    - `placeholder(string $markdown): string` — stores the Markdown and returns `<preflow-geo data-geo="{n}"></preflow-geo>`; `block(int $n): string` returns it.
    - `pageBlocks(): list<string>` — blocks added outside any component (page templates).
    - `reset(): void`.
  - Twig: `{% apply geo %}…{% endapply %}` → `GeoCollector::add()`, outputs `''`. Blade: `@geo … @endgeo`.
  - Values printed inside a geo block are auto-escaped as HTML by the engine (`Tom &amp; Jerry`); the filter/directive passes its content through `html_entity_decode($s, ENT_QUOTES | ENT_HTML5, 'UTF-8')` before `add()`, so Markdown gets plain text. Test: a block printing `Tom & Jerry's <b>` records `Tom & Jerry's <b>`.
  - `ComponentRenderer`: when the collector is capturing, every render path (`render`, `renderFragment`, `renderResolved`, `renderResolvedFragment`) wraps `renderTemplate()` in `enter()`/`leave()`; if `leave()` returns non-null, the inner HTML becomes `$collector->placeholder($block)` (the wrapper element stays). Not capturing → byte-identical output to today.

### Task 2: HTML → Markdown converter

**Files:**
- Create: `packages/view/src/Geo/MarkdownConverter.php`
- Test: `packages/view/tests/Geo/MarkdownConverterTest.php`

**Interfaces:**
- Consumes: `GeoCollector::block(int $n)` (Task 1) for placeholders.
- Produces: `final class Preflow\View\Geo\MarkdownConverter` with `__construct(?GeoCollector $collector = null)` and `convert(string $html, string $baseUrl): string` — parses with `Dom\HTMLDocument::createFromString` (`LIBXML_NOERROR`), takes `<main>` else `<body>`, removes the Global Constraints' list, converts, and returns trimmed Markdown with single blank lines between blocks.

Conversion table (exact): `h1`–`h6` → `#`…`######`; `p` → paragraph; `strong/b` → `**x**`; `em/i` → `*x*`; `a[href]` → `[text](absolute)` (text only when href is `#…` or `javascript:`; `mailto:`/`tel:` kept); `ul/ol` → `- `/`1. ` with two-space indent per nesting level; `blockquote` → `> `; `pre` → fenced block (language from `class="language-x"`); inline `code` → backticks; `img[alt]` → `![alt](absolute)`, no alt → removed; `table` → GitHub pipe table (header from `thead` or the first row); `dl` → `**term**` line + definition paragraph; `br` → line break; `hr` → `---`; `figure/figcaption` → image then caption paragraph; `<preflow-geo data-geo="n">` → `GeoCollector::block(n)` verbatim (nothing when empty); unknown elements → their children; whitespace collapsed outside `pre`; Markdown-special characters in text (`*`, `_`, `[`, `]`, `` ` ``, leading `#`/`>`/`-`/`1.`) escaped.
