# Release 0.44 checklist

Reporting and certificates for BG Genius Phase 5 (ROADMAP step 5): aggregate queries in `preflow/data` and QR
codes and PDFs from Twig or Blade templates in `preflow/view`. Spec
`docs/superpowers/specs/2026-10-28-aggregates-qr-pdf-design.md`, plan
`docs/superpowers/plans/2026-10-28-aggregates-qr-pdf.md`.

The work is on `feature/aggregates-qr-pdf`. The release is prepared (README, roadmap, this list).
It is not merged, pushed, tagged or deployed; the owner decides.

- **preflow/data:**
  - `QueryBuilder::aggregate()` returns an `AggregateQuery`: `groupBy`, `count`, `countDistinct`, `sum`, `avg`,
    `min`, `max`, `having`, `orderBy`, `limit`, `offset`, `get`. Storage drivers implement `AggregatingStorage`
    (SQLite, MySQL/MariaDB through `PdoDriver`, JSON); one conformance suite runs on all three.
  - Null rules, int-when-integral numbers, booleans as `bool`, text groups case-sensitive on every storage (MySQL
    uses `utf8mb4_bin` for groups; `where()` keeps the table collation). Refused: unknown fields, multiple
    relations, sum/avg on non-number fields.
- **preflow/view:**
  - `QrCode` (svg, png) and `qr_svg` (Twig function, Blade `@qr_svg`).
  - `PdfDocument`, `PageSettings`, `PdfRenderer` (`render()`, `html()` preview), `PdfEngine`, `MpdfEngine`,
    `PdfConfig`, `PdfResponse`; building blocks `pdf_page_number`, `pdf_page_count`, `pdf_page_break`,
    `pdf_image`, `pdf_table`, `pdf_qr`; configured fonts.
  - `config/view.php` `pdf` keys: `temp_dir`, `fonts`, `default_font`.
  - `suggest`: `mpdf/mpdf` `^8.2`, `chillerlan/php-qrcode` `^5.0` (both in `require-dev`, `require` unchanged).
- **preflow/core:** `Application` loads `config/view.php`, and binds `PdfRenderer` and `PdfEngine` (mPDF) behind
  `class_exists` checks.
- **preflow/blade:** `BladeEngine` renders an absolute template path as that exact file.

## Breaking changes

- **`Dialect` interface** (preflow/data) gained `numericValue()` and `exactText()`. A third-party `Dialect`
  must implement both. The monorepo has only the SQLite and MySQL dialects.
- **Configured PDF font names that match a bundled mPDF family are refused** (`InvalidArgumentException`);
  register the file under another name. No site configures PDF fonts yet.
- **`BladeEngine` renders absolute paths as that exact file**, no longer looked up by basename in a
  location. Sites that relied on two directories sharing a file name and the first one winning must check.

## Upgrading to 0.44: notes for site owners

- **`composer update 'preflow/*'`.** No migration, no new columns.
- **PDFs and QR codes are opt-in.** Install `mpdf/mpdf` (`^8.2`) and/or `chillerlan/php-qrcode` (`^5.0`) with
  `composer require`; they are only suggested. `pdf_image` scales with `gd`.
- **Check custom `Dialect` classes** and any PDF `fonts` config against the breaking changes above.
- **Aggregates on MySQL/MariaDB group text case-sensitively**; a site that grouped by hand and merged `a` and `A`
  gets two groups.
