# Release 0.25 checklist

MySQL / MariaDB as a first-class SQL storage. The work is on `feat/mysql-support`; the release is
prepared (README, roadmap entry, constraints) but not merged, pushed or tagged. It happens after
the final whole-branch review, under the standing go for framework releases.

Test runs before release (2026-10-23):

- `vendor/bin/phpunit` (no MySQL env): 2116 tests, 5567 assertions, 67 skipped, green.
- `composer test:mysql`: 67 tests, 313 assertions, green on a clean run. Known flake, about half
  of the runs: `CodesTest::test_redemption_recorded_without_ip_on_mysql` (codes redeemed in the
  same frozen second come back in server order; the test assumes insertion order).

- [ ] **Merge.** Fast-forward `feat/mysql-support` into `main` (run the site suites first:
  smeyer.me, preflow.dev, smart-stack.works, wherever they exist).
- [ ] **Push `main`.**
- [ ] **Tag** `v0.25.0` with the message
  `v0.25.0: MySQL and MariaDB as first-class SQL storage`, and push the tag. CI splits the packages.
- [ ] **Split workflow** succeeded.
- [ ] **Packagist** shows v0.25.0 for `preflow/data`, `preflow/folio` and `preflow/devtools`.
  **Constraints:** `preflow/folio` and `preflow/devtools` now need `preflow/data` `^0.25 || @dev`.
  No new packages.
- [ ] **Sites** move to `^0.25 || @dev` only when they use MySQL; SQLite sites see no difference
  (same DDL, no new migrations).

## For sites adopting MySQL

- `config/data.php`: a `mysql` driver with `host`, `port`, `database`, `username`, `password`
  (or `DB_*` env); see `packages/data/README.md`, section "MySQL and MariaDB".
- Index `string()` columns only; `text()` cannot be indexed on MySQL.
- `utf8mb4_unicode_ci` is case- and accent-insensitive: ids and unique values differing only in
  case collide. Generated ids are lowercase hex and unaffected.
- One connection per driver kind for now; no joins across storages.
