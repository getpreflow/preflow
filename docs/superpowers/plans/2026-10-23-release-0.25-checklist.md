# Release 0.25 checklist

MySQL / MariaDB as a first-class SQL storage. The work is on `feat/mysql-support`; the release is
prepared (README, roadmap entry, constraints) but not merged, pushed or tagged. It happens after
the final whole-branch review, under the standing go for framework releases.

Test runs before release (2026-10-23):

- `vendor/bin/phpunit` (no MySQL env): 2128 tests, 5591 assertions, 73 skipped, green
  (PHPUnit Deprecations: 99, all pre-existing).
- `composer test:mysql`: 73 tests, 338 assertions, green, three runs in a row (PHPUnit
  Deprecations: 13, pre-existing). The codes flake (same-second redemptions in arbitrary order on
  MySQL) is fixed: `Codes::redemptions()` orders by `redeemed_at`, then `id`;
  `composer test:mysql -- --filter CodesTest` passed 10 of 10 runs.
- Final-review fixes are in: ids/keys `utf8mb4_bin`, booleans bound as 1/0, codes on loose
  `max_uses`/`uses` text, the missing-column hint, 64-character names, version guards.

## For sites adopting MySQL

- `config/data.php`: a `mysql` driver with `host`, `port`, `database`, `username`, `password`
  (or `DB_*` env); see `packages/data/README.md`, section "MySQL and MariaDB".
- Index `string()` columns only; `text()` cannot be indexed on MySQL.
- Ids compare exactly (`utf8mb4_bin`: `A`, `a`, `ä` are three records). Value columns stay
  `utf8mb4_unicode_ci`, case-, accent- and trailing-space-insensitive: unique values and slugs
  differing only that way collide or shadow each other (`cafe` and `café`).
- Tested on MariaDB 10.6+ (locally MariaDB 13); MySQL 8 expected to work, not yet tested.
- One connection per driver kind for now; no joins across storages.
