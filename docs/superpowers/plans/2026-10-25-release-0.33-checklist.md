## Upgrading to 0.33 — notes for site owners

Also in the Folio README (Cache screen). Put these in the release notes.

- **`cache:clear` no longer empties `storage/cache` blindly.** It clears registered caches:
  `cache:clear <key>…` or `cache:clear --all`; `cache:list` shows keys, entries and sizes.
- **The bare `cache:clear` is deprecated:** it prints a note and does not delete anything
  outside the registry. Deploy scripts should call `cache:clear --all`.
- **Sites register their own caches** (images, flows, …) with `CacheRegistry::register()`
  (`DirectoryCache`, `FileCache` or any `CacheSource`). Files in `storage/cache` that nobody
  registered are no longer touched.
- **Site tests asserting the Settings sidebar gain "Cache"** (smart-stack.works
  `MembersGroundworkTest::test_sidebar_structure`, see above). The item needs `folio.cache`;
  staff with `*` have it, other roles need the permission granted.
- OPcache reset on the Cache screen only affects the web SAPI's cache.
