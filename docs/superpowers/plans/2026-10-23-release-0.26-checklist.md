## Release (framework)

- [ ] **Steffen creates `getpreflow/members`** (or approves `gh repo create getpreflow/members --public`)
  **and submits it on Packagist.** Nothing below runs before this.
- [ ] **Final whole-branch review** of `b4cc6ab..HEAD`.
- [ ] **Merge.** Fast-forward `feat/members-package` into `main` (run the site suites first:
  smart-stack.works, smeyer.me, preflow.dev, against the local path repos).
- [ ] **Push `main`.**
- [ ] **Tag** `v0.26.0` with the message
  `v0.26.0: preflow/members, site extensions of extension types, package defaults for lang files, session epochs, package commands`
  and push the tag. CI splits the packages (`members` is in `.github/workflows/split.yml`).
- [ ] **Split workflow** succeeded, including `getpreflow/members`.
- [ ] **Packagist** shows v0.26.0 for `preflow/members`, `auth`, `folio`, `i18n`, `devtools`, `data`.
- [ ] **Constraints** (already in the branch): `preflow/members` needs `preflow/auth`, `folio`,
  `i18n`, `devtools`, `data` and `validation` `^0.26 || @dev`; `preflow/folio` needs `preflow/data`
  and `preflow/auth` `^0.26 || @dev`.

## smart-stack.works (after the tag)

no visible change and no data migration.

- [ ] In the site: `composer update 'preflow/*'` (pulls v0.26.0 and `preflow/members`); run its
  suite once more.
- [ ] Merge the site branch into its `main`.
- [ ] **Steffen runs the deploy.** Afterwards: `preflow members:prune` is the cron line as before
