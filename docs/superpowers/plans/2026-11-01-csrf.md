# CSRF for Every Form Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Check every unsafe request (with or without a session) by the browser's origin signals plus a token, and stop long-open forms from failing.

**Architecture:** `preflow/core` gets two pure pieces (`OriginCheck`, `StatelessCsrfToken`) and a rewritten `CsrfMiddleware` that decides per request from the cookie, the session and the origin verdict. Route-level exemption is an attribute read by `preflow/routing` into its route entries and carried on core's `Route`; the middleware matches the route once for unsafe requests and the `Kernel` reuses that match. Expired sessions on non-sign-in paths are answered by a default responder that keeps the posted fields as flashed old input, which validation, form and members read.

**Tech Stack:** PHP 8.5, PSR-7/15, PHPUnit 11. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-01-csrf-design.md`

## Global Constraints

- `preflow/core` must not depend on `preflow/routing` or `preflow/i18n` (both are optional packages; use `class_exists` / container lookups as `Application` already does).
- Unsafe methods: `POST`, `PUT`, `PATCH`, `DELETE`. Safe: `GET`, `HEAD`, `OPTIONS`.
- Token field `_csrf_token`, header `X-CSRF-Token` (unchanged).
- Stateless token: HMAC-SHA256 with `app.key`, slot length 86400 s, valid in the current and previous slot.
- Built-in default key string `preflow-default-key-change-me!!` (Application.php) and an empty key both disable the stateless token.
- `/--component/` stays exempt by default.
- Config file `config/csrf.php` with keys `exempt`, `trusted_origins`, `sign_in_paths`; a missing file means the defaults.
- Paths are matched after `LocaleMiddleware` stripped the locale prefix (it runs before the session and CSRF middleware already; do not move it).
- Every comparison of a secret uses `hash_equals`.
- Release: 0.51.0 (ROADMAP current-state line, upgrade notes in the ROADMAP item).

## Review Focus

1. A POST with `Sec-Fetch-Site: same-site` from a sibling subdomain not in `trusted_origins` → refused even with a valid session token (Task 2 table test `test_same_site_is_refused_unless_trusted`).
2. An expired session on a locale-prefixed sign-in path (`/de/konto/login` → stripped `/konto/login`) → let through (Task 5 `test_expired_session_on_a_localized_sign_in_path_passes`).
3. A multipart POST with a file and an expired session → 303 back, file not kept, text fields kept, password fields not kept (Task 4 `test_old_input_never_keeps_passwords_tokens_or_files`).
4. A POST to a path with no route, same-origin → the kernel's 404, not a 403; cross-site → 403 (Task 3 `test_unmatched_route_falls_through_to_404_when_origin_passes`).
5. Folio's own forms that print the `CsrfToken` attribute keep working on a live session, and a public page's form prints a stateless token through that attribute (Task 3 `test_token_attribute_is_stateless_without_session`, Task 5 Folio integration test).

**Interfaces:**
- Consumes: Task 1 `Route::$csrfExempt`, `RouterInterface`; Task 2 `OriginCheck`, `OriginVerdict`, `StatelessCsrfToken`.
- Produces: `final readonly class CsrfConfig { list<string> $exempt = ['/--component/'], list<string> $trustedOrigins = [], list<string> $signInPaths = []; static fromFile(string): self }`.
- Produces: `final class CsrfSignInPaths { public function add(string $path): void; public function matches(string $path): bool }` — bound as a container singleton in `bootCsrf` before providers run; exact path match after trimming a trailing slash.
- Produces: `CsrfToken::stateless(string $value): self` (named constructor) and `CsrfToken::isStateless(): bool`; the `CsrfToken` request attribute is set on every request (session token with a session; else the stateless token when enabled; else not set).
- Produces: `CsrfMiddleware::__construct(CsrfConfig $config, OriginCheck $origin, StatelessCsrfToken $stateless, CsrfSignInPaths $signIn, ?string $sessionCookie, ?\Closure $router /* fn(): ?RouterInterface */, ?ExpiredSessionHandler $expiredSessionHandler, ?\Closure $expiredResponder /* Task 4 */)`.
- Produces: `CsrfMiddleware::REFUSED_REASON` request attribute is not needed; refusals throw `ForbiddenHttpException('CSRF check failed: <reason>.')` with reason `origin`, `token`, `no-signal`.

Decision order for an unsafe request (implement exactly; this is the spec's table):
1. Path in `exempt` (prefix) → pass.
2. Request has an `Authorization` header and no cookies at all → pass.
3. Route lookup (only when a router is available): `match()`; on `NotFoundHttpException` continue as not exempt; on match set the request attribute `Route::class`; `csrfExempt` → pass.
4. Origin verdict `Refuse` → 403 (`origin`).
5. No session on the request, or the request carries no session cookie (`$sessionCookie ?? session_name()` in `getCookieParams()`): `Pass` → pass; `Unknown` → the submitted token must `verify()` as stateless, else 403 (`no-signal`).
6. Session alive (it held a token before this request): submitted must equal the session token (`hash_equals`), else 403 (`token`).
7. Session new: submitted stateless token that verifies and verdict `Pass` → pass (owner's option a). Submitted non-empty other token: verdict `Unknown` → `CsrfSessionExpiredException` as today; verdict `Pass` and `CsrfSignInPaths` matches → pass; else the site's `ExpiredSessionHandler` response if any, else `$expiredResponder` (Task 4), else `CsrfSessionExpiredException`. Nothing submitted → 403 (`token`).

Safe requests: set the `CsrfToken` attribute and pass.

### Task 4: Default answer for an expired session, with old input kept

**Files:**
- Create: `packages/core/src/Http/Csrf/ExpiredSessionResponder.php`, `packages/core/src/Http/OldInput.php`
- Modify: `packages/core/src/Application.php` (bind `OldInput`, pass the responder to the middleware), `packages/validation/src/ValidationExtensionProvider.php`, `packages/form/src/FormExtensionProvider.php`, `packages/members/src/MembersView.php`
- Test: `packages/core/tests/Http/Csrf/ExpiredSessionResponderTest.php`, `packages/core/tests/Http/OldInputTest.php`, one test each in validation, form and members

**Interfaces:**
- Produces: `final class OldInput { public const string FLASH_KEY = '_old_input'; public static function keep(SessionInterface $s, array $parsedBody): void; public function all(): array; public function get(string $field, mixed $default = null): mixed }` — `keep()` drops `_csrf_token`, every key whose name contains `password` (case-insensitive, at any depth), and never stores uploaded files; `all()` reads the flash of the current request's session (request-scoped service; empty without a session).
- Produces: `final class ExpiredSessionResponder { public function __invoke(ServerRequestInterface $request): ResponseInterface }` — never calls the app. Full POST: `OldInput::keep`, `flash('warning', message)`, 303 to the Referer's path+query when the Referer's origin equals the request's, else `/`. htmx (`HX-Request: true`): same flash and old input, `204` with `HX-Refresh: true`. `Accept: application/json` without htmx: `409` JSON `{"error":"session_expired"}`.
- Message: English `Your session had expired. Please send the form again.`; German `Deine Sitzung war abgelaufen. Bitte sende das Formular noch einmal.`; French `Votre session avait expiré. Veuillez renvoyer le formulaire.`; Italian `La sessione era scaduta. Invia di nuovo il modulo.` — chosen by the request's locale (the attribute `LocaleMiddleware` sets, else `app.locale`); a site's translator key `csrf.session_expired` wins when the i18n `Translator` is in the container and `has()` it.
- Consumers: validation's `old()` and form's `oldInput` use their own input first, then `OldInput::all()`; `MembersView` merges `OldInput::all()` into `old` / `old_email` when the controller passed none.
