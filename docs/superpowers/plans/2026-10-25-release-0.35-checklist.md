# Release 0.35 checklist

Media release 2 in `preflow/media`, with the Folio library UI on top. Replace a file and keep
earlier versions (`media:versions:prune`), extra asset fields and `MediaLibrary::query()`,
colour management to sRGB (Imagick with lcms; default CMYK profile FOGRA39L, CC0), PDF previews
(`media:previews`), colours (`color`, `palette`, `text_color`; `media_colors()`,
`media_color_class()`, `media_image(…, {placeholder: true})`; `media:colors`). Folio: replace,
versions, extra fields, filters, previews and swatches in the library, `media-versions/` in
export and import, `assets.view` staff may open private files, previews and versions (earlier
versions are staff only). Extra fix
in Folio: `hreflang` and canonical URLs use `app.url`. The work is on `feat/media-0.35`. The
release is prepared: media README, Folio README, roadmap entry, spec, constraints. It is not
merged, pushed or tagged; the owner decides.

Constraints: `preflow/media` requires `preflow/data ^0.35 || @dev` (conflict `<0.35`): the data
package changed (in `whereAny()` groups, `=` with a null value compiles to `IS NULL` on SQL; the query builder
reads relations from the queried definition, which `query()` needs for the code-defined asset
type). `preflow/folio` requires `preflow/media ^0.35 || @dev` and `preflow/data ^0.35 || @dev`
(conflicts `<0.35`). Core, view and devtools stay at `^0.34` (no change in them).

## Upgrading to 0.35: notes for site owners

Also in the media README and the Folio README. Put these in the release notes.

- **Nothing changes for existing assets.** They read as version 1, unedited, without colours.
  File names, URLs and the frontend HTML stay as they are (the release 1 fixture is
  byte-identical). sRGB and untagged images keep the same backend and files.
- **`versions_dir`** (`config/media.php`, default `storage/media-versions`) holds the earlier
  files of replaced assets. Like `private_dir` it must be outside `public/` and the media dir
  (refused at boot) and **must be a Deployer shared dir**.
- **New config keys** in `config/media.php`: `versions_dir`, `fields`, `filters`,
  `color_profile_cmyk`, `ghostscript`, `pdftocairo`. All optional.
- **New template functions:** `media_preview_url()`, `media_colors()`, `media_color_class()`;
  `media_image()` takes `placeholder: true`. CSS variables: `--media-color`,
  `--media-color-rgb`, `--media-text`, `--media-palette-1` … `-N`, from a CSP-nonce'd head
  style (no inline styles). Example: `background: rgba(var(--media-color-rgb), .8)`.
- **New commands** (need `preflow/devtools`): `media:versions:prune`, `media:previews`,
  `media:colors`. `media:previews`, `media:colors` and `media:variants` take `--limit=N` (and
  `--offset=N`) for chunked runs and print the command for the next chunk.
- **Uploads do more work at once:** an upload (and a replace or restore) makes the variants,
  the colours and a PDF's preview in the same request; a PDF can add up to 30 seconds.
- **`media_image()` on a PDF** shows its preview (or poster) as a picture once a preview
  exists; before, it was a link. Previews appear on upload and after `media:previews`.
- **Colour-accurate CMYK variants need Imagick (with lcms).** Without it a CMYK or
  non-sRGB-profiled image gets no variants and the asset's `note` says
  `needs Imagick for colour-accurate variants`.
- **PDF previews need Ghostscript 10.03.1 or newer, or Poppler's `pdftocairo`.** An older
  Ghostscript is never run on uploads (published `-dSAFER` escapes). With `pdftocairo` print
  PDFs (CMYK with an output intent) are less colour-true.
- **Private files:** staff with `assets.view` may open private files and private previews in
  the Folio library, next to `private_permission`.
- **Earlier versions: staff only.** `{private_url}/{id}/v/{n}` needs `assets.view`; a member's
  `private_permission` never opens them (a 403, no login redirect). The request carries
  `PrivateFileAccess::VERSION`, so a site's own rule can tell them apart (the core default
  still denies everything).
- **Export / import** carry `media-versions/` (an archive without it leaves local versions
  alone; into a site without `versions_dir` the version files are skipped with a notice).
- **`hreflang` and canonical URLs** (`alternates[].href`) use `app.url` when it is set and
  absolute; before, the request's host. A site on several hostnames now names one.
- **Data:** in a `whereAny([...])` group, `['field', '=', null]` compiles to `IS NULL` on SQL,
  so it matches a missing or NULL field as on the JSON driver. `where('field', '=', null)` is
  unchanged.
- **SQL storage:** `preflow migrate` adds the new asset columns (`version`, `versions`,
  `preview`, `color`, `palette`, `text_color`, `note` and one per extra field), all text.
