# Release 0.23 checklist

Every step is gated by the user. Nothing here is done yet: the 0.23 work is on
`feat/relation-picker`, and the release is prepared (roadmap entry, README) but not merged,
pushed or tagged.

1. **Merge.** Merge `feat/relation-picker` into `main` locally (the sites symlink the
   packages, so run all site suites first: smeyer.me, preflow.dev and smart-stack.works,
   wherever they exist).
2. **Push `main`.**
3. **Tag** `v0.23.0` with the message
   `v0.23.0: Folio multi-relation fields as checkbox chips with a filter`,
   and push the tag. CI splits the packages.
4. **Packagist.** No new packages this release, so the CI ping updates all of them.
   **Constraints.** No package's `require` list changes: the picker uses no new core, data or
   auth API, so folio keeps its constraints on those. Only sites that want the picker raise
   their constraint on `preflow/folio` to `^0.23 || @dev` (see step 5).
   **Preflight (after the tag is on Packagist, before deploying):** in a temp copy of
   smart-stack.works run `php deploy/server-composer.php`, then
   `composer update "preflow/*" --no-dev` against Packagist, then the site suite.
   No migrations come with 0.23.
5. **Sites.** Sites stay on their current minor until they want the picker; then they move to
   `preflow/folio` `^0.23 || @dev`.

## For sites adopting 0.23

- **Multi relations render as checkbox chips**, not a native multi-select. The posted data is
  the same (`name[]`), so storage, validation and existing records are unchanged.
- **A filter input** appears above 12 options (client-side; it posts nothing).
- **`"relation": {"orderBy": "<field>"}`** is new and optional; without it the order is as before.
- **Markup change:** a multi relation is now `<fieldset class="folio-relation folio-relation-multi">`
  with a `<legend>`, no longer `<div>` + `<label for>` + `<select>`. Site CSS or tests that
  targeted `select[multiple]` for these fields need updating.
- Single relations are unchanged. Nothing in 0.23 needs a config key or a migration.
