# Release 0.22 checklist

Every step is gated by the user. Nothing here is done yet: the 0.22 work is on
`feat/folio-admin-polish`, and the release is prepared (roadmap entry, README) but not merged,
pushed or tagged.

1. **Merge.** Merge `feat/folio-admin-polish` into `main` locally (the sites symlink the
   packages, so run all three site suites first: smeyer.me, preflow.dev and smart-stack.works,
   wherever they exist).
2. **Push `main`.**
3. **Tag** `v0.22.0` with the message
   `v0.22.0: Folio read-only display, panel-only actions, badge columns, side panels, tabs`,
   and push the tag. CI splits the packages.
4. **Packagist.** No new packages this release, so the CI ping updates all of them.
   **Constraints.** No package's `require` list changes: folio's 0.22 features use no new
   core, data or auth API, so folio keeps `^0.21 || @dev` on those. Only sites that use a
   0.22 feature raise their constraint on `preflow/folio` to `^0.22 || @dev` (see step 5).
   **Preflight (after the tag is on Packagist, before deploying):** in a temp copy of
   smart-stack.works run `php deploy/server-composer.php`, then
   `composer update "preflow/*" --no-dev` against Packagist, then the site suite.
   No migrations come with 0.22.
5. **Sites.** smeyer.me and preflow.dev stay on their current minor. Only the smart-stack.works
   feature branch moves to `preflow/folio` `^0.22 || @dev`; until then it keeps its 0.21
   constraint.

## For sites adopting 0.22

- **Read-only fields now show display values.** A read-only select shows its option label, a
  relation its record labels, a roles list comma-separated, a date formatted for the admin,
  and rich text its sanitised markup. Before, the raw stored value was shown. Stored data is
  unchanged.
- **Dates in the admin are formatted** ("22 Oct 2026", "22 Oct 2026, 23:15" with `time`) in
  list cells and read-only fields. Only `Y-m-d`, `Y-m-d\TH:i` and ISO 8601 with an offset are
  parsed; anything else is shown as stored. The frontend output does not change.
- **`#[RecordAction]` takes `toolbar: false`** (default `true`, so existing actions keep
  their header button).
- **`#[ListColumn]` may return `Badge`** (default is still a string).
- **`#[FormPanel(position: 'side')]`** is new; `before` and `after` behave as before.
- **Tabs:** `data-folio-tabs` markup is new; no existing markup changes.
- Nothing in 0.22 needs a config key or a migration.
