# Release 0.47 checklist

AI connection and auto-translate. Spec: `docs/superpowers/specs/2026-10-30-ai-translation-design.md`, plan:
`docs/superpowers/plans/2026-10-30-ai-translation.md`.

- **preflow/ai (new package, split repository `getpreflow/ai`):** `AiClient` with Claude and Gemini, keys from the
  environment, price table, usage log without text, `ai:check`, `ai:usage`, `Testing\FakeAiClient`.
- **preflow/i18n:** machine translation (`Machine\*`): units, layered tuning, glossary, `MarkupCheck`, `Estimator`,
  `TextSource` and `JobRunner`. Requires `preflow/ai ^0.47`.
- **preflow/folio:** Translate button with side-by-side review, whole-type runs as drafts, "not checked" markers
  (`publishing.checked_translations`), labels and media alt texts, Settings → AI, permissions `ai.translate` and
  `ai.settings`. Requires `preflow/ai` and `preflow/i18n ^0.47`. AI stays off until `config/ai.php` is enabled and a
  key is set.

## Breaking changes

- **SQL sites must run `preflow migrate`** after upgrading: the `_translated_source` and `_machine_translated`
  columns are written on every translation save, with AI off too.
