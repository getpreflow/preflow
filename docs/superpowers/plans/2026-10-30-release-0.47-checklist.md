## Found after the release (released as v0.47.1 on 2026-10-30, all four sites deployed)

- A Translate click held the PHP session (file lock) for the whole translation, so every other request of the same
  browser waited minutes. AI requests now close the session before asking the provider.
- A full 12,000-character batch answered with 7,500-8,000 tokens and hit the 8,000 cap; cut answers were paid again.
  Output room is now a token per character (8,000 to 32,000), and estimates count two characters a token.
