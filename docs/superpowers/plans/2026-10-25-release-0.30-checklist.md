## Upgrading to 0.30 — notes for site owners

Also in the Folio README (Screen assets). Put these in the release notes.

- **Asset files:** only `css`, `js`, `mjs`, `map`, `svg`, `png`, `webp`, `woff2` and `json`,
  lower-case extension; each path segment `[A-Za-z0-9._-]`, no leading dot. Anything else is a 404.
- **No PHP in an extension's `assets/`:** extension discovery scans every `.php` file under
  the extension folder, `assets/` included.
- **`@folio/`** offers `htmx.js` and `trix` only.
- **`editor_assets`** is Folio-internal; extensions use `assets:`.
- A listed file that is missing (for example deleted after a deploy) throws an
  `ExtensionException` naming the screen or panel.
- Asset caching: `immutable` only for a `?v=` matching the file's current hash; other
  requests (lazy imports, CSS `url()`) revalidate with `no-cache` + `ETag` (304).
- Extension pages stay under the strict CSP: no inline scripts or styles.
