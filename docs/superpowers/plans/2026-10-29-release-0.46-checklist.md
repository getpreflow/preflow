# Release 0.46 checklist

This release closes the generic gaps from BG Genius Phase 3, the move of the site's own admin onto Folio in English
and German. Afterwards the three sites are upgraded, and BG Genius goes live on 0.46 without its workarounds. Plan:
`docs/superpowers/plans/2026-10-29-folio-gaps-0.46.md`.

Not released yet.

- **preflow/validation:** `step:n` rule (`Rules\Step`): a whole multiple of `n` from 0, float-safe; strings
  `validation.step` in en, de, fr.
- **preflow/folio:**
  - Number field option `"step"` (a positive number or `"any"`). It is rendered on the input, and the server checks
    `numeric` plus the step. Without it, nothing changes.
  - Share links ("Copy preview link") work on every language tab. `FrontendResolver::pathFor()` gives the path
    without the locale prefix, and the shared preview compares that path.
  - `publishing.revisions` `0` or `null` keeps every revision; a negative value is an error.
  - `cache_path` in `config/folio.php` (default `storage/cache`). It holds `folio-extensions.cache`,
    `folio-blocks.cache` and `folio-translations-{locale}.php`.
  - The media core's HEIC messages are translated (`folio.assets.core.heic_unsupported`, `heic_failed`). An asset
    field's upload refusal is shown in the interface language, as the library screen already does.
  - Conflicts with `preflow/validation <0.46`.
- **preflow/i18n:** `LocaleMiddleware::urlPrefix()`: the prefix stripped from the current request (`/de`, or `''`).
- **preflow/htmx:** `HtmxExtensionProvider` takes an optional `pathPrefix` closure. Core passes the locale prefix,
  so `hd.actionUrl()`, `hd.post()`, `hd.get()` and `hd.on()` on a `/de/…` page build `/de/--component/…`. The
  action then runs in German through `LocaleMiddleware`. Token, endpoint and CSRF exemption are unchanged.
- **preflow/core:** wires the prefix; registers the `LocaleMiddleware` instance; conflicts with `preflow/htmx <0.46`
  and `preflow/i18n <0.46`.
- **preflow/data:** `Table::unique(...$columns)` and `Table::index(...$columns)` for composite unique and plain
  indexes in migrations. Without arguments they mark the last column (as `index()` does today). Names are
  `uniq_{table}_{a}_{b}` / `idx_{table}_{a}_{b}`, shortened past 64 characters.
- **preflow/media:** HEIC and HEIF become JPEG assets on upload, import and replace when Imagick has HEIC support
  (`HeicConverter`, default `ImagickHeicConverter`). The JPEG is upright with orientation 1 and keeps its ICC
  profile and EXIF. The HEIC original is not kept. Without HEIC support, the file is refused with a clear message
  and nothing is stored.

## Breaking changes

None expected. Two changes in behaviour, both harmless for the three sites:

- **`'publishing' => ['revisions' => 0]`** kept only the latest revision until now, which was undocumented. It now
  keeps all. None of the three sites sets it.
- **HEIC/HEIF uploads** were refused as "type not allowed". Now they are stored as JPEG, or refused with the HEIC
  reason.

## Upgrading to 0.46: notes for site owners

- **`composer update 'preflow/*'`.** There is no new column. `preflow migrate` is only needed where a deploy runs it
  anyway (holz-objekte.org).
- **Decimals:** add `"step": 0.5` (or `"any"`) to a number field that takes decimals.
- **Component URLs on prefixed pages now start with `/de/--component/`.** A site whose own JavaScript or templates
  match `/--component/` at the start of a URL, or write `hx-post="/--component/…"` by hand, should use
  `hd.actionUrl()` or match `--component/` anywhere in the path.
- **HEIC:** check the server with `php -r 'print_r(Imagick::queryFormats("HEI*"));'`. Without it, HEIC uploads are
  refused with the reason. GD alone cannot read HEIC.
- **Tests that boot the app:** set `cache_path` in the test config to a temp dir.

## BG Genius (after the sites, its own session)

BG Genius goes live on 0.46 and removes its workarounds:

- [ ] **PageLocale for actions:** drop the signed locale prop. Actions on `/de/…` pages now run in German through
  the URL prefix.
- [ ] **Id-based uniqueness:** replace it with `$t->unique('player_token', 'game')` in a migration for the app table.
  Check existing rows for duplicates first.
- [ ] **`revisions => 100`:** set `0` (keep all), or keep a number if it wants a cap.
- [ ] **Test cache guard:** set `cache_path` in the test config and remove the guard around `storage/cache/folio-*.cache`.
- [ ] **HEIC in its AssetImporter extension list:** remove it. `MediaLibrary` converts or refuses HEIC itself. Check
  the live server's Imagick for HEIC first.
- [ ] **Number fields with decimals:** add `"step"` where the admin needs them.
- [ ] **German share links:** check one from a German tab on the live site.
