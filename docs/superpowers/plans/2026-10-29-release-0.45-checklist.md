# Release 0.45 checklist

Translation status for BG Genius Phase 3 (the generic Folio part): Folio knows which translatable texts a language
misses or holds outdated, shows it in the list and the form, offers "still correct", and can refuse to publish while
a visible language is incomplete. Plan `docs/superpowers/plans/2026-10-29-translation-status.md`.

The work is on `feature/translation-status`. The release is prepared (README, roadmap, this list); nothing is merged,
pushed or tagged yet.

- **preflow/folio:**
  - `TranslationStatus` (`texts()`, `missing()`, `outdated()`, `confirm()`, `stamp()`, `fingerprint()`) and
    `TranslatableText`: every translatable text of a record, with a stable path (`title`, `sections.{uid}.headline`,
    `{field}.{own path}`) and a label. Missing: the default language has the text, the language has none. Outdated:
    the fingerprint saved with the translation differs from the current default text.
  - `ReportsTranslatableTexts` for field types that keep locale maps inside their value; `BlocksFieldType`
    implements it (nested blocks included). Booleans, uploads, assets, env names and readonly or hidden fields are
    not texts.
  - `_translated_from` (`{locale: {path: fingerprint}}`) on the record, stamped when a translation is saved (form,
    autosave, preview share the factory). It is content, not publishing metadata, so "still correct" makes a
    published record "changed".
  - Admin: list badges per language (`de · 2 missing`, `de · 1 outdated`, `de`); language tabs with counts;
    outdated fields marked with a "Still correct" button (a field with block texts: "N texts outdated");
    route `POST {prefix}/{type}/{id}/_translations/confirm` (`locale`, optional `path`, `_version`; needs
    `{type}.edit`; a stale `_version` is a 409; redirects to the form with the notice `folio.form.confirmed`).
  - `Publisher` refuses to publish while a language in `_locales` misses a text, opt-in with
    `config/folio.php` `'publishing' => ['complete_languages' => true]` (`ValidationException` key
    `_translations.{locale}`, string `folio.publish.incomplete`). The draft is saved; the scheduler reports it as
    failed. Outdated never blocks.
  - Strings in `lang/{en,de,fr}`: `folio.list.outdated`, `folio.form.outdated`, `folio.form.outdated_texts`,
    `folio.form.still_correct`, `folio.form.confirmed`, `folio.publish.incomplete`.

## Breaking changes

- **The list badge counts every text the default language has, not only required fields.** `de · 2 missing` for a
  record whose required title and slug are empty in German becomes `de · 3 missing` when the body has an English
  text too. Sites or tests that match the old numbers must be updated.
- **`AdminController::languageBadges()` returns `list<array{text, state}>`** (`state`: `missing`, `outdated` or
  `ok`) instead of strings; `_list_results.twig` uses `state`. A site that overrides that template and matches the
  word "missing" in the badge must use `badge.state` and `badge.text`.
- **New column `_translated_from`** on SQL-backed Folio record tables (and their `__published` and `__revisions`
  tables): run `preflow migrate`. JSON storage needs nothing. Until it runs, saving a translation on a SQL type
  fails on the unknown column.

## Upgrading to 0.45: notes for site owners

- **`composer update 'preflow/*'`, then `preflow migrate`** (adds `_translated_from` on SQL-backed types).
- **Nothing is outdated at first.** Only translations saved after the upgrade carry a fingerprint; older ones are
  never marked. A record becomes "outdated" in a language once its default text changes after that.
- **Missing counts grew** (see breaking changes): the list now counts optional texts too.
- **Opt in to complete languages** with `'publishing' => ['complete_languages' => true]` in `config/folio.php`.
  Records visible in a language that misses a text then stay drafts until it is filled in or the language is
  switched off under "Visible in".
- **Custom field types** with locale maps in their value implement `ReportsTranslatableTexts` to take part; without
  it their texts are not counted.
