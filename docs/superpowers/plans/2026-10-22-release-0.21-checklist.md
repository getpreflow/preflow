# Release 0.21 checklist

Every step is gated by the user. Nothing here has been executed: no push, tag, publish or deploy.

1. **Merge.** Merge `feat/members-step2-framework` into `main` locally (the sites symlink the
   packages, so run both site suites first).
2. **Push `main`.**
3. **Tag** `v0.21.0` with the message
   `v0.21.0: atomic throttle and code uses, tokens, remember-me, Folio user provider, frontend gate, private assets, nav badges`,
   and push the tag. CI splits the packages.
4. **Packagist.** No new packages this release, so the CI ping updates all of them.
   **Constraints.** `auth`, `codes` and `folio` now require `^0.21 || @dev` of the packages whose
   0.21 features they use (auth: core, data; codes: data; folio: core, data, auth). `core` stays
   free of a `preflow/data` constraint: its Throttle already needed the DataManager in 0.20 and
   is only bound when `config/data.php` exists.
   **Preflight (after the tag is on Packagist, before deploying):** in a temp copy of
   smart-stack.works run `php deploy/server-composer.php`, then
   `composer update "preflow/*" --no-dev` against Packagist, then the site suite, then
   `preflow migrate` (new tables `auth_tokens` and `auth_remember`, plus the `private` column
   of the asset library).
5. **Sites stay on their current minor** (smart-stack.works and smeyer.me on 0.20 / 0.19, preflow.dev
   on 0.19) until plan D (members area under /tools), which requires `^0.21` and adds the
   config keys (`remember`, `frontend.permission`, `assets.private_*`). Without those keys the
   0.21 packages behave as before: no remember cookie, no gate, public assets only, no badge.
