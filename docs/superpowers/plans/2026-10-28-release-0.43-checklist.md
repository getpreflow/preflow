# Release 0.43 checklist

Media for the BG Genius migration (ROADMAP step 4): copies of an asset with makers and remake, a bin for
every delete, opt-in cleanup of unused assets, video previews with ffmpeg, private `importFile()`, and the
matching Folio screens. Spec `docs/superpowers/specs/2026-10-28-media-copies-cleanup-video-design.md`, plan
`docs/superpowers/plans/2026-10-28-media-copies-cleanup-video.md`.

The work is on `feature/media-copies-cleanup-video`. The release is prepared (README, roadmap, this list).
It is not merged, pushed, tagged or deployed; the owner decides.

- **preflow/media:**
  - Copies: `Asset::$derivedFrom`, `$maker`, `$makerParams`, `$derivedVersion`, `isCopy()`;
    `MediaLibrary::derive()`, `makeCopy()`, `copies()`, `copyCounts()`; `query(copies:)` hides copies unless
    asked or searched; the core usage source `CopyReferences` (a live copy is a use of its original).
  - Makers: `Derived\DerivedMaker`, `DerivedMakers` (the maker `copy` is reserved), `remake()`, `canRemake()`,
    `isStale()`.
  - The bin: `bin_dir` (no default; without it delete keeps removing for good and `preflow migrate` warns),
    every delete bins, `findBinned()`, `binned()`, `restoreFromBin()`, `emptyBin()` (`BinEmptyResult`),
    `media:bin` (list, `--restore`, `--empty`, `--limit`, `--offset`), `binned_at` (UTC).
    `AssetUsageEntry::$blocksDelete`; posters of binned assets and revisions are non-blocking uses.
  - Cleanup: `config/media.php` `cleanup` (`enabled` false, `min_age_days` 7, `bin_days` 30),
    `Cleanup\AssetCleanup`, `media:cleanup` (`--delete`, `--kind`, `--by`, `--private`/`--public`,
    `--older-than`, `--limit`, `--offset`). Kinds are image, video, document.
  - Video previews: `Preview\VideoPreviewRenderer`, `ffmpeg` and `ffprobe` in `config/media.php`,
    `media:previews` covers videos; an image poster wins in `thumbnailUrl()` and `media_image()`.
  - `importFile(..., private: true)`.
  - New columns on the asset table: `derived_from`, `maker`, `maker_params`, `derived_version` (number),
    `binned_at`.
- **preflow/folio:** the bin page (`{prefix}/assets/bin`, restore), "Moved to the bin" notice and a warning
  without `bin_dir`; revisions count as usages (non-blocking); "Unused only" filter when cleanup is on;
  stacks (bubble with the number of copies, the picker opens a stack), the copies panel, "Make a copy and
  edit it", "Remake from original", the "original changed" mark; binned assets in fields show "(in the bin)".
  New `folio.assets.*` texts in en/de/fr (German "du").

## Upgrading to 0.43: notes for site owners

- **`composer update 'preflow/*'`, then `preflow migrate`** on SQL sites (in the deploy). It adds the new
  columns `derived_from`, `maker`, `maker_params`, `derived_version` and `binned_at`. Do it before the new code
  serves requests: queries read `derived_from` and `binned_at`. JSON-storage sites need nothing.
- **Set `bin_dir`** per site in `config/media.php`, to a shared deploy directory (`storage/media-bin`, added to
  `shared_dirs` in `deploy.php` and git-ignored), or the next release deletes the bin. Without `bin_dir` deletes
  remove files for good as before (migrate and Folio's library warn). JSON sites without Folio get no migrate
  warning.
- **Cleanup is off.** Turning it on needs every place that stores asset ids or URLs to report them through an
  `AssetReferenceSource`; read the warning box in the media README first.
- **A delete no longer frees disk space at once** with `bin_dir` set: files wait in the bin until
  `preflow media:bin --empty` (older than `cleanup.bin_days`). Schedule it, in chunks (`--limit`).
- **Copies are hidden from lists** (`query()`), shown as stacks in Folio's library; search finds them.
- **`find()` and `all()` skip binned assets.**
- **Video previews** need ffmpeg (`ffmpeg` and `ffprobe` in `config/media.php` for a static build). Without it
  videos keep today's tile.
- **New texts:** `folio.assets.*` in en/de/fr.
