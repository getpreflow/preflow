# Release 0.36 checklist

Media release 3 in `preflow/media`, with the image editor in Folio. Box presets (`height` and
`fit` in `config/image.php`: `cover` cuts the box's ratio around the focal point or a per-format
crop, `contain` keeps the whole image, `max` is today's behaviour), image edits (rotate, mirror,
crop) that render a master while the original stays untouched, per-format crops,
`media_original_url()`. Folio: an "Edit image" screen (rotate, mirror, crop with ratios, one cut
per box preset) with Cropper.js 1.6.2 (MIT, vendored). The work is on `feat/media-0.36`. The
release is prepared: media README, Folio README, roadmap entry, spec, plan, constraints. It is
not merged, pushed or tagged; the owner decides.

Constraints: `preflow/folio` requires `preflow/media ^0.36 || @dev` (conflict `<0.36`): Folio
calls `MediaLibrary::rotate()`, `flip()`, `setCrop()`, `setFormatCrop()`, `formatRegion()`,
`orientedUrl()` and `Formats`. `preflow/media` is unchanged (data `^0.35`, core and view
`^0.34`). Folio's `ComposerConstraintsTest` pins the new conflict. Other packages stay as they
are.

## Upgrading to 0.36: notes for site owners

Also in the media README and the Folio README. Put these in the release notes.

- **Nothing changes for untouched assets and width-only presets.** Existing assets read as
  unedited (`rotation` 0, no flip, no crops, no master). File names, URLs and the frontend HTML
  stay as they are (the release 1 fixture is byte-identical). A preset without `height` behaves
  as before (`fit` defaults to `max`).
- **Box presets.** A preset with `height` and `fit: cover` or `contain` is a box (it also needs
  `width`; `widths` default to 1x and 2x of it). The name must match `^[a-z][a-z0-9-]*$`, must
  not be `edit`, `preview` or `oriented`, must not start with `edit-`, `preview-` or
  `oriented-`, and must not be `v<digits>` or `v<digits>-…`. Anything else is a boot error that
  names `config/image.php` and the preset. Check existing preset names that you will turn into
  boxes. `max` presets keep any name.
- **Box variants are made on first request**, not at upload: the first browser to ask for a
  file gets it cut (like step widths), then the web server serves it. `warm_on_upload` and
  `media:variants --all` make them in advance (use one on shared hosting). Any edit or focal
  point change deletes the asset's box files; they are made again under new names (the name
  carries a key of the box, region and focal point).
- **Editing works on public JPEG, PNG, WebP and AVIF images only.** Private images, GIF and SVG
  are refused. Without Imagick, a CMYK or wide-gamut image that is edited gets no master (the
  asset's `note` says `needs Imagick for colour-accurate variants`) and pages keep the original.
- **`url()` and `media_url()` deliver the master for an edited image**; documents keep their
  file URL. The new `media_original_url()` gives the untouched original (a legacy upload path
  gives its legacy URL). Folio's panel has *Download original*.
- **A per-format crop is clamped to the image crop**: box files are cut from the master, which
  no longer holds the cropped-away area. To art-direct outside the image crop, remove the image
  crop first.
- **New reserved asset field names:** `rotation`, `flip`, `crop`, `crops`, `master`. A site that
  uses one as an extra field in `config/media.php` `fields` must rename it before upgrading.
- **Custom image backends:** `ImageBackend` gained `writeEdited()` (renders the master), and
  `writeVariants()` jobs may carry a `crop`. A third-party backend must implement
  `writeEdited()`; the GD and Imagick backends do.
- **Colours and variants follow the master** for edited images: colours are read from the
  delivered image, and step-width variants are `{stem}-edit-{key}-{w}.{fmt}`.
- **Folio:** an *Edit image* screen at `{prefix}/assets/{id}/edit` (permission `assets.edit`, the one replace uses), with the vendored Cropper.js 1.6.2
  (MIT).
- **SQL storage:** `preflow migrate` adds the new asset columns (`rotation`, `flip`, `crop`,
  `crops`, `master`), all text.

## Sites (after the tag)

- [ ] **Raise the sites' `preflow/*` constraint** to `^0.36 || @dev` and run
  `composer update 'preflow/*'`, then the suite. Ship the bump, the lock and the deploy together.
- [ ] **Check preset names** in each site's `config/image.php` against the box name rules before
  adding `height` to a preset. smeyer.me's temporary `smoke-thumb` preset (added for a browser
  test) is not part of the release: remove it or turn it into a real preset.
- [ ] **Optional, after deploy:** `php preflow media:variants --all --limit=200` makes the box
  variants in advance, then the printed `--offset` commands. The live server kills SSH
  processes after about 12 minutes, so run it in chunks with `/opt/alt/php85/bin/php`.
- [ ] **Imagick** is still needed on the server for colour-accurate CMYK variants and masters
  of CMYK or wide-gamut images.
- [ ] **holz-objekte.org (before it upgrades):** still needs `storage/media-versions` as a
  shared dir and the `AssetInUseException` handling noted in the 0.34 and 0.35 checklists.
