# preflow/media

The asset library for Preflow: uploads, responsive image variants (WebP/AVIF) and private
files. Folio adds the admin screens on top; the core works without it.

Work in progress: this package currently holds the asset value classes (`Asset`, `Variant`,
`AssetUploadException`) and the image backends (`Preflow\Media\Image\*`).

## Install

```
composer require preflow/media
```
